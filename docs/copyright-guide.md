# 著作権・使用許可 確認ガイド

## 確認の流れ

### 1. 管理団体の確認
JASRACまたはNexToneが管理している楽曲かを調べる。

- JASRAC 作品データベース：https://www.jasrac.or.jp/ejmd/
- NexTone 作品検索：https://search.nex-tone.co.jp/

どちらかが管理していれば、**YouTubeへの投稿は基本的に許諾済み**（JASRAC/NexToneとYouTubeが包括契約を結んでいるため）。

### 2. Content ID（収益化への影響）
管理楽曲は Content ID により広告収益が原盤権者に行く場合がある。  
→ 収益化を目指す場合は「音楽配信サービス向けインスト」「公式カラオケ音源」を使うのが安全。

### 3. ニコニコへの投稿
- JASRAC 管理楽曲：ニコニコと包括契約あり → 投稿OK
- NexTone 管理楽曲：個別に確認が必要な場合あり

### 4. インスト音源の選び方
優先順位：
1. 公式が配布しているカラオケ音源
2. YouTube公式アーティストチャンネルの音源（利用規約要確認）
3. 楽曲提供者が「歌ってみた利用OK」と明記している配布音源
4. ニコニコ等で配布されている公認インスト

### 注意
- 「フリー」と書いてあっても商業利用不可の場合がある
- インスト配布者の規約を必ず確認してURLとともに記録に残す
