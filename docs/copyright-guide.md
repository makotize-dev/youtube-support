## 権利の全体像

歌ってみた1本には、性質の違う複数の権利が同時にかかっている。**著作権法**という1本の法律が、2つのカテゴリ（著作権・著作隣接権）をまとめて定めている。

```
著作権法
│
├── 著作権（＝著作者の権利）
│   ├── 複製権（第21条）          ★歌ってみたで関係
│   ├── 公衆送信権（第23条）       ★歌ってみたで関係
│   │     └ 「送信可能化権」を含む（＝ネットにアップする権利）
│   └── その他（演奏権・翻案権・譲渡権 …）
│
└── 著作隣接権（＝楽曲を世に伝えた人の権利）
    ├── 実演家の権利
    ├── レコード製作者の権利 ＝ 通称「原盤権」（第96条〜）  ★歌ってみたで関係
    ├── 放送事業者の権利
    └── 有線放送事業者の権利
```

★印が、歌ってみた投稿で実際に関係する権利。以下、この系統に沿って説明する。**著作権と原盤権は別系統の権利であり、それぞれ別々にクリアする必要がある。**

> 「著作権」という語は、広く著作権法全体を指すことも、狭く「著作者の権利」だけ（著作隣接権と並ぶ片方）を指すこともある。このガイドでは文脈で使い分ける。

## 著作権 — 曲そのものの権利

- **守るもの**：楽曲そのもの（作詞・作曲という創作）。料理でいう「レシピ」にあたる。
- **持つ人**：著作者 ＝ 作詞家・作曲家
- **根拠法**：著作権法 第17条以下

### 歌ってみたで関係する2つの権利

| 権利 | 内容 | 動画投稿との関係 |
|---|---|---|
| **複製権**（第21条） | 楽曲を録音・録画して動画の形にする | 動画を「作る」段階 |
| **公衆送信権**（第23条） | 動画をネット上で公衆が見られる状態にする | 動画を「公開する」段階 |

歌ってみたを1本投稿するには、**この両方がクリアされている必要がある**。どちらか一方では足りない。

> 公衆送信権のうち、ネットにアップする部分を「**送信可能化権**」と呼ぶ。JASRAC/NexTone の検索画面の「配信」欄や、このプロジェクトで「配信」と呼ぶものは、これにあたる。

**処理**：著作権は多くの場合 JASRAC または NexTone が管理。YouTube・TikTok は両団体と包括契約しているため、管理されている楽曲はカバーされる（→「管理団体」の節）。

## 原盤権 — 録音物の権利

- **正体**：業界用語。法律上は著作隣接権のうち「**レコード製作者の権利**」。著作権とは別系統。
- **守るもの**：その楽曲を録音した「録音物そのもの」。同じ曲でも録音ごとに別々に発生する。「レシピで実際に作られた一皿」にあたる。
- **持つ人**：レコード製作者 ＝ その音を最初に録音物に固定した者（著作権法 第2条第1項第6号）。実務上はレコード会社が多い。ボカロ曲など作者自身が録音した場合は作者本人。
- **根拠法**：著作権法 第96条〜第97条の3（複製権・送信可能化権など）
- **処理**：包括契約の対象外。使うインスト音源の「録音物」が誰のものかで決まる。YouTube/TikTok では Content ID が実務上の行使ツール（→「Content ID」の節）。

> 著作隣接権には、実演家・レコード製作者・放送事業者・有線放送事業者の4種類の権利者がいる。歌ってみたで実務上問題になるのはレコード製作者の権利＝原盤権。実演家（演奏者）の権利も隣接権にあるが、Content ID は「録音物」を照合する仕組みなので、実務上は原盤権に注目すれば足りる。

## 2つを並べて

| | 著作権 | 原盤権 |
|---|---|---|
| カテゴリ | 著作権 | 著作隣接権 |
| 守るもの | 曲（レシピ） | 録音物（一皿） |
| 持つ人 | 作詞家・作曲家 | レコード製作者（多くはレコード会社） |
| 根拠法 | 著作権法 第17条以下 | 著作権法 第96条〜 |
| 歌ってみたでの処理 | JASRAC/NexTone の包括契約 | 使うインスト次第。Content ID で検知 |

同じ「ray」という曲でも、BUMP本人の録音・カラオケ会社の録音・友人の歌ってみた録音は、それぞれ別の「一皿」＝**別の原盤**。著作権は1つ（曲は同じ）だが、原盤権は録音ごとに別々に発生する。

> **権利を行使するとどうなるか**：原盤権者は、無断で複製・配信されたとき法的には差止請求・損害賠償請求ができる。YouTube/TikTok の実務では Content ID により「収益化（広告収益を取る）／ブロック／追跡」を選べる。

**「JASRAC管理曲だから安心」は著作権の話でしかない。** 原盤権（＝どのインストを使うか）は別途考える必要がある。

## 管理団体（JASRAC / NexTone）

楽曲の著作権は、多くの場合 JASRAC または NexTone が管理している。

- JASRAC 作品検索（J-WID）: https://www2.jasrac.or.jp/eJwid/
- NexTone 作品検索: https://search.nex-tone.co.jp/

### 「一部管理」に注意 ← 最重要ポイント

管理団体は、楽曲の**すべての権利を管理しているとは限らない**。権利の種類ごとに「管理する／しない」が分かれていることがある（＝一部管理）。

NexTone の検索結果は、権利ごとに ○（管理）／✕（管理外）が表示される。歌ってみたで見るべき欄は：

- **配信** → ○ なら、YouTube・TikTok の包括契約でカバーされる
- **複製・ビデオ** → ✕ なら、複製の許諾を別ルートで確保する必要がある（次節）

「管理団体に登録があるから投稿OK」と単純に判断しない。**どの権利が ○ か**を必ず確認する。

### 包括契約とは

YouTube と TikTok は JASRAC・NexTone と「包括契約」を結んでいる。これにより、これらの団体が管理する楽曲は、利用者が個別に許諾を取らなくても投稿できる（プラットフォームが代わりに使用料を支払う仕組み）。

ただし包括契約がカバーするのは、**その団体がその楽曲について管理している権利の範囲だけ**。一部管理の ✕ 部分は包括契約ではカバーされない。

## 複製権が管理対象外のとき

NexTone が「複製・ビデオ」を管理していない（✕）場合、複製の許諾は**権利者本人から**得る必要がある。

ボカロ曲では、これが自然に満たされることが多い：

- ボカロP（作者）が **オフボーカル音源を公式配布**している → 「歌ってみたに使ってよい」という権利者の意思表示であり、複製許諾の根拠になる
- 作者のガイドラインやニコニ・コモンズの登録に、二次利用条件が明記されていることもある

> **実例：** 「天才ロック」（烏屋茶房）は NexTone が配信○・複製✕ だったが、作者が原曲概要欄でオフボーカルを公式配布していたため、複製の穴が埋まり投稿可能と判断した（→ `../candidates/天才ロック.md`）。

## Content ID と音源マッチ（収益化・削除リスク）

Content ID は、アップロードされた動画の**音声を、権利者が登録した「原盤（マスター音源）」と照合**する YouTube の仕組み。一致すると、原盤権者は広告収益の取得・ブロック・追跡などを選べる。TikTok にも同様の音源マッチの仕組みがある。

これは前節の**原盤権を行使する実務上のツール**。著作権（JASRAC/NexTone の管理）とは別の話で、「JASRAC管理曲だから Content ID が当たる」のではなく、**公式の原盤と一致する音を使ったときに当たる。**

### リスクを避けるには

公式の原盤と一致しない音源を使えば、Content ID・音源マッチは作動しにくい。逆に**避けるべきは、公式音源からボーカルを除去しただけのインスト**——原盤と一致するため、ほぼ確実に検知される。

> **J-POP の歌ってみたでは Content ID が当たるのが通常の状態。** 動画が消えるわけではなく、多くは「広告収益が原盤権者に流れる」結果になる。投稿の妨げにはならないが、その動画を自分で収益化することは難しくなる。市販のカラオケ系インストも、そのカラオケ会社が自分の録音を Content ID 登録していることが多い。

## プラットフォーム別のまとめ

| プラットフォーム | 著作権の扱い |
|---|---|
| YouTube | JASRAC・NexTone と包括契約あり。管理されている権利はカバーされる |
| TikTok | JASRAC・NexTone と包括契約あり。YouTube と同様 |
| X (Twitter) | 包括契約が弱い。ただし hi-to0 は **音なしで投稿**するため、X 上では音楽著作権の問題が発生しない |

## インスト音源の選び方

優先順位（上ほど安全）：

1. 公式が配布しているカラオケ音源（メーカー製）
2. 作者・アーティスト本人が配布するオフボーカル
3. 「歌ってみた利用OK」と明記された配布音源
4. MIDI起こし・耳コピのインスト（最終手段）

選んだら、**配布元のURLと利用規約を必ず記録に残す**。

---

## 注意点

- 「フリー」と書かれていても商用利用不可の場合がある。規約の本文を読む
- インスト配布者の規約は、URLとともに記録に残す（後日トラブル時の証拠になる）
- **Web検索やAIの要約を鵜呑みにしない。** 著作権番号などは一次情報（JASRAC/NexTone の公式検索）で裏取りする。過去に、検索要約がニコニコ動画のサイト共通許諾番号を「作品コード」と取り違えた例があった
- 同名異曲が多い。作詞・作曲者名、アーティスト名で必ず突き合わせる
