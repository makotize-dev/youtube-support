## 原盤権 / Content ID

著作権とは別系統の権利（→ [copyright-guide.md](../docs/copyright-guide.md) の「原盤権」節）。

- BUMP OF CHICKEN は Toy's Factory 所属の大手バンド。**公式オフボーカル配布なし**
- 市販カラオケ系インスト（例：歌っちゃ王「ray(ガイド無しカラオケ)」）が複数入手可能
- どのインストを使っても、Content ID（YouTube）・音源マッチ（TikTok）の対象になる可能性が高い
  - 公式音源加工 → BUMP の原盤と一致して確実に検知
  - 市販カラオケ系 → カラオケ会社が自分の録音を Content ID 登録していることが多い
- 結果として広告収益は原盤権者（レーベル or カラオケ会社）に流れる可能性が高い

**友人方針：案C（Content ID 当たる前提）。** チャンネルとして同様の運用を継続中。
