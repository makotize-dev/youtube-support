# YouTube チャンネル運営サポート

**対象チャンネル：** [hi-to0](https://youtube.com/@hi-to0)  
**担当：** 安河内（事務作業全般）

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `songs/` | 楽曲ごとの作業フォルダ（インスト調査・著作権・説明文・タグ） |
| `templates/` | 繰り返し使うテンプレート（説明文・SNS投稿文など） |
| `analytics/` | 再生数・登録者数の定期記録 |
| `coconala/` | MIX出品ページ・受注管理 |
| `twitch/` | 配信開設・準備チェックリスト |
| `docs/` | 運営方針・著作権ガイドなど参考資料 |

## 作業フロー（1曲あたり）

```
1. songs/ に楽曲フォルダ作成
2. インスト音源の調査・入手先を記録
3. 著作権・使用許可の確認
4. YouTube説明文・タグを下書き
5. サムネイルチェックリスト確認（Canva作業は友人側）
6. YouTube / ニコニコ 投稿
7. SNS告知文を投稿
8. analytics/ に投稿後データを記録
```

## チャンネル概要

- 登録者：約200人
- 動画本数：48本（本編24本・Shorts24本）
- 総視聴数：約7万回
- ジャンル：J-POPカバー（歌ってみた）
- 投稿ペース：月1本（Shortsとセット）
