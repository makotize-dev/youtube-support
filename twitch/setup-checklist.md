# Twitch 配信開設チェックリスト

## アカウント・初期設定
- [ ] Twitch アカウント作成（または既存アカウント確認）
- [ ] プロフィール画像・バナー設定
- [ ] チャンネル説明文を記入
- [ ] パネル（配信説明・SNSリンク等）設定

## 配信ソフト設定（OBS等）
- [ ] OBS Studio または Streamlabs インストール
- [ ] Twitchストリームキー取得・設定
- [ ] 配信品質設定（解像度・ビットレート）
- [ ] ゲームキャプチャ設定確認
- [ ] マイク・音声設定確認

## 著作権・BGM
- [ ] ゲーム配信の著作権ポリシー確認（パブリッシャーごと）
- [ ] 配信BGMに著作権フリー音源を使用するか検討

## 配信告知
- [ ] X（Twitter）での告知テンプレート作成 → sns-template.md
- [ ] YouTube コミュニティ投稿での告知検討

## Twitch アフィリエイト条件（参考）
- フォロワー50人
- 30日間で500分以上の配信
- 30日間で7日以上の配信
- 30日間で平均3人以上の同時視聴者
